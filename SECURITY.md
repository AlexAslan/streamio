# Security policy

## Supported versions

Only the latest released version receives security fixes.

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/AlexAslan/streamio/security/advisories/new)
rather than a public issue. Include a description, reproduction steps (ideally a minimal input file),
and the affected version. You can expect an initial response within a few days.
